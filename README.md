# 💰 Cofrinho

> Plataforma de controle e planejamento financeiro pessoal com Inteligência Artificial.

Transforme seus dados financeiros em informações úteis através de dashboards, metas, projeções, relatórios em PDF e interação por linguagem natural.

🌐 **Demo:** [https://SEU-LINK-AQU](https://guii-pzz.github.io/Cofinho-page/)I

📂 **Repositório:** [SEU-LINK-AQUI](https://github.com/Guii-pzz/Cofinho-page)

---

## 📖 Sobre o projeto

O Cofrinho nasceu de uma necessidade real.

Minha mãe costumava organizar dívidas e compromissos financeiros em anotações no papel. Eu já utilizava planilhas para controlar minhas próprias finanças e decidi transformar essa necessidade em uma aplicação web.

O objetivo inicial era simples: facilitar o acompanhamento financeiro.

Durante o desenvolvimento, o projeto evoluiu para uma solução que reúne controle financeiro, metas, projeções, relatórios e Inteligência Artificial para auxiliar o usuário na tomada de decisões.

## 💬 Linguagem Natural

Além de responder perguntas, a IA pode interagir com os dados da aplicação.

Exemplos:

```text
Quanto falta para atingir minha meta?

Quanto já investi?

Qual é o meu patrimônio projetado?

Adicionar R$ 2.000 na meta do carro.
```

A aplicação interpreta a solicitação e realiza a operação correspondente.

# 🔐 Privacidade

Um dos objetivos do projeto foi manter os dados sob controle do usuário.

As informações financeiras são armazenadas localmente no navegador utilizando Local Storage.

O Cofrinho não possui um banco de dados centralizado armazenando informações financeiras dos usuários.

### Fluxo atual

```text
Usuário
   │
   ▼
Aplicação Web
   │
   ▼
Local Storage
```

### Importante

Os dados podem ser perdidos caso:

- O navegador seja limpo
- Outro dispositivo seja utilizado
- Outro navegador seja utilizado
- O usuário utilize navegação privada
